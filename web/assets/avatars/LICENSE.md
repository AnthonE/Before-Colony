# The avatars' sources and licences

The store's traders wear these on the Exchange floor (`bc_client_core::avatar`, `docs/FLOOR.md`).
Each file here is made from its original by `scripts/avatars/prep.py` (textures cut down, facial
blend shapes dropped, the arms brought down out of the T-pose); the originals aren't kept here.

- The VRoid models: VRoid Studio's sample models, released by VRoid under CC0, as collected at
  <https://opengameart.org/content/vroid-studio-cc0-models>. Each file's own VRM metadata also
  allows use by anyone, commercial use, modification and redistribution, with no credit required.

  <https://github.com/mrdoob/three.js/tree/dev/examples/models/gltf/RobotExpressive> (its README:
  "CC0 1.0"), copied unchanged.

No credit is required by any of them; this file gives it anyway.
